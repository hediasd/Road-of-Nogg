# Nogg Terminal -- pixel glyph source.
#
# This file is the source of truth for the font. The PNG atlas and the FontFile
# resource beside it are BUILD OUTPUTS: regenerate them with
#
#   Godot_v4.4-stable_win64.exe --headless --path . --script res://scripts/bake_bitmap_font.gd
#
# Never hand-edit the outputs; edit a glyph here and re-bake.
#
# --- The grid -------------------------------------------------------------
#
# Every glyph occupies the same 8 x 12 cell and every glyph advances 8. The
# face is monospaced by construction, not by convention, which is what gives it
# the terminal-readout rhythm of the reference.
#
#   row  0      top leading, always empty
#   rows 1-8    cap / ascender band (8 rows)
#   rows 4-8    x-height band (5 rows)
#   -- baseline sits immediately below row 8 --
#   rows 9-10   descender band
#   row  11     bottom leading, always empty
#
# Ascent is therefore 9 and descent 3. Bodies occupy columns 1-6, leaving a
# one-pixel bearing on each side; symmetric glyphs (I T Y i l t + | etc.) use
# columns 1-5 so their centre stem lands exactly on column 3.
#
# --- The style rules ------------------------------------------------------
#
# These are what keep 95 hand-drawn glyphs reading as one face. Breaking one is
# a decision to make deliberately, not by accident while nudging a letter.
#
#   1. Stroke is always exactly one pixel. Weight is never added by thickening.
#   2. Round letters are octagons: corners clipped exactly one pixel, no more.
#      There are no curves in this font, only clipped corners.
#   3. Terminals are flat and grid-aligned. No pixel dangles diagonally off the
#      end of a stroke.
#   4. Diagonals are single-pixel staircases, and appear only where the letter
#      genuinely demands one (A K M N V W X Y Z / \ and the digits 0 1 2 4 7).
#   5. Counters are at least two pixels wide, so they survive the retro
#      viewport's downsample instead of filling in.
#
# --- The format -----------------------------------------------------------
#
# `@ <hex codepoint> <label>` opens a glyph; the next 12 lines are its rows.
# `#` is ink, `.` is empty. Blank lines and lines starting with `#` in the
# ROW position are not permitted -- the baker requires exactly 12 rows of
# exactly 8 characters and fails loudly otherwise, because a silently short
# glyph would ship as a garbled letter rather than as an error.
